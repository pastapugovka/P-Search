## 🚀Быстрый запуск

```bash
git clone https://github.com/pastapugovka/P-Search.git
cd P-Search
bun install
bun run dev
```

Сервис поднимется на `http://localhost:3000` с 38 демонстрационными документами:

```bash
curl "http://localhost:3000/api/health"
curl "http://localhost:3000/api/search?query=поиск"
```

## 🧠Обучение на данных

P-Search самостоятельно изучает содержимое вашего сайта. Два режима:

- **🗃️ Только данные из набора** — словарь, основы и подсказки собираются из `SEARCH_DATA`; результат предсказуем
- **📊 Данные + обучение на запросах** — движок запоминает, что и как ищут: частые запросы всплывают первыми, «Возможно, вы имели в виду…» точнее понимает формулировки

Режим задаётся в `.env`: `SEARCH_LEARN=dataset` или `SEARCH_LEARN=queries`.

В обоих режимах обучение строит словарь по реальному контенту, приводит слова к основам (RU/EN), берёт подсказки **из ваших данных** и прощает опечатки.

## 📥Настройка сбора данных

1. Укажите источник в `.env`: `SEARCH_DATA=./data/контент-моего-сайта.json`
2. Подготовьте документы в простом формате
3. Подключите дополнительные источники через панель «/P»

Каждый документ — простой JSON:

```json
{
  "id": "docker-intro",
  "title": "Docker: контейнеры для вашего приложения",
  "content": "Docker упаковывает приложение вместе с окружением в образ.",
  "keywords": ["docker", "контейнеры"],
  "tags": ["docker", "devops"],
  "category": "инфраструктура",
  "link": "/guide/docker/intro"
}
```

`keywords` — ассистент ранжирования, `category` и `tags` — фильтры контекста «@» и «#».

> [!IMPORTANT]
> Изменили данные? Перезапустите сервис — индекс перестроится за миллисекунды.

## 📦Данные и бэкапы

- **Корпус** — `SEARCH_DATA`, по умолчанию `data/search-content.json`
- **Бэкапы включены по умолчанию**: словарь, частоты, статистика запросов и корпус сохраняются в базу данных
- **База** — локальная `DATABASE_URL` (PostgreSQL через Prisma) или облачная: VK Cloud, Яндекс Облако, Cloud.ru, Google Cloud, AWS, MongoDB Atlas, Neon, Supabase, Redis, Turso Cloud, Upstash, MotherDuck, Convex
- **Обучение переживает остановку сервиса** и восстанавливается при запуске
- **Отключить** бэкапы: `SEARCH_BACKUP=false` — обучение живёт только в памяти и сбрасывается при остановке

Экспорт и импорт набора: `/export` · `/import` в палитре или `GET/POST /api/dataset`.

Откат и сброс: бэкапы включены — `/restore` откатывает к последнему состоянию из базы; отключены — полный сброс при остановке. Новый корпус — измените `SEARCH_DATA`; демо-набор — `data/search-content.json` из репозитория.

## 🎨Палитра команд «/»

Символ `/` открывает палитру: навигация — стрелки, выполнение — `Enter`, закрытие — `Esc`.

**Работа с поиском:**

- `/help` — справка · `/clear` — очистить запрос и результаты · `/history` — история запросов

**Данные и обучение:**

- `/export` — экспорт набора в JSON · `/import` — импорт набора из JSON
- `/backup` — сохранить бэкап обучения · `/restore` — откатить к последнему бэкапу

**Интерфейс:**

- `/lang` — язык · `/theme` — светлая, тёмная и авто-тема · `/bot` — боты и их команды

Команды ботов появляются в палитре **автоматически** после привязки — см. «🤖Боты».

> 💡 Полный список команд, API, переменных окружения и скриптов — в [**`COMMANDS.md`**](./COMMANDS.md).

## 🔌Провайдеры «/P» — выбор модели

`/P <провайдер> --source <ключ> --model <модель>` подключает модели и источники данных: **75+ провайдеров, включая Claude, GPT, Gemini**. После подключения модель доступна в любом клиенте.

```bash
/P anthropic --source sk-ant-xxx --model claude-3-5-sonnet --async
/P openai   --source sk-xxx     --model gpt-4o            --async
/P google   --source AIza-xxx   --model gemini-1-5-pro    --async
```

Флаги: `--source` (ключ или путь) · `--model` (модель) · `--format` (`json`/`csv`/`xml`/`api`) · `--sync`/`--async` · `--disconnect`.

## 🔮Предиктивный поиск и ИИ-режим

- **Предиктивный поиск** — подсказки по мере ввода, обученные на вашем контенте
- **ИИ-режим** — движок готовит контекст из топ-документов, а модель отвечает на его основе: RAG «поиск + генерация»

Модель подключается один раз в «/P» и работает в любом клиенте.

## 🧭Контекст «@»

`@` и `#` сужают поиск до категории и тегов, подсказки выпадают сразу после ввода. Два режима:

- **1 · С добавленным контекстом** — контекст добавляется к запросу и фильтрует выдачу
- **2 · На основе контекста** — контекст становится основой запроса, слова дополняют результат

```text
@инфраструктура docker  → docker в категории «инфраструктура»
#поиск стемминг         → стемминг среди документов с тегом «поиск»
@категория #тег         → комбинированный фильтр
```

## 🤖Боты

Привязка бота добавляет его команды в палитру «/» у любого клиента — без перезапуска фронтенда.

1. Запустите бота на Bun, Python, Node.js или Discord.js
2. Привяжите одной командой — и команды сразу появятся в палитре:

```bash
curl -X POST "http://localhost:3000/api/bots" \
  -H "Content-Type: application/json" \
  -d '{"name":"мой-бот","platform":"discord","commands":["/search","/stats"]}'
```

Или `BOT_NAME=мой-бот` в `.env` — команды появятся автоматически.

## 🔗API

Все запросы — на `http://localhost:3000/api/…`:

- `GET/POST /api/search` — поиск · `GET /api/suggest` — подсказки · `GET /api/context` — категории, теги, статистика
- `GET /api/documents` — документы · `GET /api/providers` — каталог провайдеров
- `GET/POST /api/dataset` — экспорт/импорт набора · `POST /api/backup` · `POST /api/restore` — бэкапы
- `GET/POST/DELETE /api/bots` — боты · `GET /api/health` — статус

Параметры: `limit` · `category`/`tags` · `fuzzy` · `lang` (`auto`/`ru`/`en`). Операторы: `+обязательное` · `-исключить` · `"фраза"` · `@категория` · `#тег`.

Настройка движка — через `.env`:

```env
SEARCH_DATA=./data/search-content.json
DATABASE_URL=postgres://user:pass@localhost:5432/psearch
SEARCH_LEARN=dataset
SEARCH_BACKUP=true
SEARCH_TITLE_WEIGHT=5.0
SEARCH_KEYWORDS_WEIGHT=2.5
SEARCH_BODY_WEIGHT=1.0
SEARCH_K1=1.2
SEARCH_B=0.75
SEARCH_LIMIT=20
SEARCH_SNIPPET_WIDTH=42
SEARCH_MAX_FRAGMENTS=2
SEARCH_MARK_TAG=mark
SEARCH_LEVENSHTEIN_LIMIT=2
SEARCH_FUZZY=true
SEARCH_LANG=auto
```

Каждый параметр меняется на лету — без правки кода.

## ☑️Частые вопросы

- **Почему так быстро?** Индекс в памяти: сборка ~10 мс, запрос **0.1–1 мс**, без дисковых обращений
- **Обучение сохраняется при остановке?** Да: бэкапы включены по умолчанию, данные в базе (локальной Postgres/Prisma или облачной) восстанавливаются при запуске. Без бэкапов — полный сброс
- **Как поменять данные?** Отредактируйте `SEARCH_DATA` (или путь) и перезапустите, либо импортируйте набор через `/import`
- **Как подключить к своему приложению?** REST API (`/api/search`) или типизированный SDK в `src/lib/client` — браузер, сервер, десктоп
